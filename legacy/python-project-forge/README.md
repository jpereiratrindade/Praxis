# Project Forge Python — implementação de referência

Esta pasta preserva o MVP Python que validou o fluxo inicial de criação de
projetos. Ele não é mais o núcleo oficial do SisTer-HOA.

O núcleo oficial passa a ser o executável C++23 `sister-ops`.

O protótipo permanece temporariamente para comparação comportamental durante a
migração dos comandos `project catalog`, `plan`, `apply`, `verify` e `inspect`.
