# ADR-0005 — Praxis as product identity

## Status
Accepted.

## Decision
The product formerly named **SisTer-HOA** is named **Praxis**.

Praxis implements a **Governed Operational Harness (HOA)**. HOA remains the architectural concept; Praxis is the concrete tool.

The rename is not cosmetic. It records an ontological transition from a component identified with the SisTer ecosystem to a general instrument for governed experimentation over workspaces.

## Compatibility
- `praxis` is the canonical CLI.
- `hoa` is retained temporarily as a compatibility alias.
- `sister-ops` is retained temporarily for legacy workflows.
- Historical ADRs, RFCs and Git history are not rewritten.
